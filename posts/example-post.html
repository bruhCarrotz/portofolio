An Example Post

May 2026 LearningAdvisory

This is what an HTML post looks like. Because each post is a plain HTML fragment, you have complete control over the content — no markdown limitations.

What you can do

Use any standard HTML elements: headings, paragraphs, lists, images, tables, iframes, or anything else. The post-body stylesheet in post.html handles the typography automatically.

  • Bold and emphasis work as expected
  • Links go to external sites naturally
  • Images just need a valid src

Callout boxes

Tip: Use the .callout class on a <div> for highlighted notes, warnings, or key takeaways.

Callouts are great for surfacing important points without breaking the reading flow.

Use blockquotes for pull quotes, references, or anything you want to visually offset from the main text.

How to add your own posts

  1. Add an entry to posts.js with a unique slug, title, description, date, and tag.
  2. Create posts/your-slug.html — copy this file as a starting point.
  3. That's it. No build step, no markdown parser, no CMS.

Delete this post by removing its entry from posts.js and the posts/example-post.html file.
